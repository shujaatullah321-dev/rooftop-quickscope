# Hand in Hand — يَدًا بِيَد

A cooperative walking adventure for a Muslim husband and wife: 30 tasks across 6 chapters (Home, Garden, Souq, Desert, Night Oasis, Masjid at Fajr) that can only be solved together, on one phone, tablet or computer.

- Play on the web: https://shujaatullah321-dev.github.io/rooftop-quickscope/hand-in-hand/
- Android app: https://github.com/shujaatullah321-dev/rooftop-quickscope/releases/tag/hand-in-hand

The game is one small HTML file (`app/src/main/assets/www/index.html`, about 65 KB) and works offline. The app needs no permissions.
