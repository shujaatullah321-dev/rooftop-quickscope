# Hand in Hand — يَدًا بِيَد

A cooperative walking adventure for a Muslim husband and wife: 100 tasks across 20 chapters that can only be solved together. Part 1 (tasks 1–30) teaches the basics; Part 2 (tasks 31–100) goes deeper: taking turns, walking in step, mirror steps, a shared step budget, levers that open one door and close another, sliding sand and the lookout tower. Everything runs on one phone, tablet or computer.

- Play on the web: https://shujaatullah321-dev.github.io/rooftop-quickscope/hand-in-hand/
- Android app: https://github.com/shujaatullah321-dev/rooftop-quickscope/releases/tag/hand-in-hand

The game is one small HTML file (`app/src/main/assets/www/index.html`, about 105 KB) and works offline. The app needs no permissions.
